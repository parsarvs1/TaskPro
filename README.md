# TaskPro 🚀

A simple and modern task manager built with HTML, CSS and JavaScript.

## Features

- ➕ Add tasks
- ☑️ Complete tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- 🔴🟡🟢 Task priorities
- 🌙 Dark Mode
- 💾 LocalStorage
- 📊 Progress tracking
- 🔎 Task filtering
- ↕️ Task sorting

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage
